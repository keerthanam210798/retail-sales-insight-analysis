# Retail Sales Performance & Business Analysis

## Business Problem
The retail company wanted better visibility into sales performance,
profit drivers, and the impact of discounts to support data-driven decisions.

## Objectives
- Analyze sales and profit trends
- Identify high and low performing regions and products
- Evaluate discount impact on profitability

## Tools Used
- SQL for data analysis
- Python for data cleaning
- Power BI for visualization

## Dataset
Public Superstore sales dataset
