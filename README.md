# Retail Sales Insight Analysis

## Overview

This project analyzes retail sales data to derive business insights using **Python, SQL, and Power BI**. It demonstrates an end-to-end data analytics workflow from data cleaning to visualization.

## Objectives

* Analyze sales by category and region
* Track monthly sales trends
* Identify top-performing products

## Tools Used

* Python (Pandas)
* SQL
* Power BI
* Git & GitHub

## Key Steps

* Cleaned and prepared data using Python
* Performed aggregations and analysis using SQL
* Built an interactive Power BI dashboard with slicers

## Dashboard Highlights

* KPI cards: Total Sales, Total Orders
* Sales by Category (Bar Chart)
* Monthly Sales Trend (Line Chart)
* Sales by Region (Bar Chart)
* Top 10 Products (Donut Chart)

## Summary

This project showcases practical data analytics skills including data preparation, analysis, and dashboard development.
